# 🎓 BrightMind - منصة التعليم الإلكتروني

منصة تعليمية إلكترونية حديثة ومتكاملة تقدم تجربة تعليمية تفاعلية للطلاب والمتعلمين.

## 📋 نظرة عامة على المشروع

**BrightMind** هي منصة تعليم إلكتروني شاملة مصممة لتوفير دورات تدريبية متنوعة في مجالات مختلفة مثل تطوير الويب، علم البيانات، التسويق الرقمي، والتصميم. المنصة مبنية باستخدام تقنيات الويب الحديثة وتوفر واجهة مستخدم سهلة وجذابة.

## 📄 شرح الملفات والصفحات

### 1. **index.html** - الصفحة الرئيسية
- **الوظيفة**: الصفحة الأولى التي يراها الزائر
- **المحتوى**:
  - قسم Hero بتصميم جذاب
  - عرض الدورات المميزة
  - إحصائيات المنصة
  - الشهادات والتقييمات
  - نموذج التسجيل في الدورات

### 2. **courses.html** - صفحة الدورات
- **الوظيفة**: عرض جميع الدورات المتاحة
- **المحتوى**:
  - نظام فلترة الدورات حسب الفئة (تطوير الويب، علم البيانات، التصميم، إلخ)
  - بطاقات الدورات التفاعلية
  - معلومات تفصيلية لكل دورة (المدة، عدد الطلاب، التقييم)
  - أزرار التسجيل المباشر

### 3. **about.html** - صفحة من نحن
- **الوظيفة**: التعريف بالمنصة ورسالتها
- **المحتوى**:
  - رؤية ورسالة المنصة
  - القيم والمبادئ
  - إحصائيات النجاح
  - فريق العمل
  - الشركاء والمدربين

### 4. **contact.html** - صفحة التواصل
- **الوظيفة**: التواصل مع فريق الدعم
- **المحتوى**:
  - نموذج اتصال تفاعلي مع التحقق من البيانات
  - معلومات الاتصال (البريد الإلكتروني، الهاتف، العنوان)
  - خريطة الموقع
  - روابط وسائل التواصل الاجتماعي
  - الأسئلة الشائعة (FAQ)

## 🎨 ملفات الأنماط (CSS)

### **css/style.css**
يحتوي على جميع الأنماط المخصصة للموقع:

#### المتغيرات (CSS Variables):
```css
--primary-color: #007bff
--secondary-color: #6c757d
--success-color: #28a745
--warning-color: #ffc107
```

#### الأقسام الرئيسية:
- **Navigation Styles**: تنسيقات شريط التنقل
- **Hero Section**: تصميم القسم الرئيسي بتدرجات لونية
- **Course Cards**: بطاقات الدورات التفاعلية
- **Animations**: حركات وتأثيرات CSS
- **Responsive Design**: تصميم متجاوب لجميع الأجهزة
- **Forms**: تنسيق النماذج والأزرار
- **Footer**: تصميم ذيل الصفحة

## 💻 ملفات JavaScript

### **js/script.js**
يحتوي على جميع الوظائف التفاعلية للموقع:

#### الوظائف الرئيسية:

1. **initSmoothScroll()**
   - تفعيل التمرير السلس عند النقر على الروابط الداخلية
   - تحسين تجربة المستخدم

2. **initContactForm()**
   - التحقق من صحة بيانات نموذج الاتصال
   - التحقق من البريد الإلكتروني
   - عرض رسائل الخطأ والنجاح
   - إرسال البيانات

3. **initCourseFilter()**
   - فلترة الدورات حسب الفئة
   - إظهار/إخفاء الدورات ديناميكياً
   - تحديث واجهة المستخدم

4. **initNavbarScroll()**
   - تغيير مظهر شريط التنقل عند التمرير
   - إضافة/إزالة الظل والخلفية

5. **initAnimations()**
   - تفعيل الحركات عند التمرير
   - إضافة تأثيرات بصرية تفاعلية

## 🚀 كيفية تشغيل المشروع

### الطريقة الأولى: فتح مباشر
1. افتح مجلد المشروع
2. انقر مرتين على ملف `index.html`
3. سيفتح الموقع في متصفحك الافتراضي

### الطريقة الثانية: استخدام Live Server (مستحسن)
1. افتح المشروع في VS Code
2. انقر بزر الماوس الأيمن على `index.html`
3. اختر "Open with Live Server"
4. سيفتح الموقع على `http://localhost:5500`

### الطريقة الثالثة: استخدام Python Server
```bash
# في مجلد المشروع
python -m http.server 8000

# ثم افتح المتصفح على
http://localhost:8000
```

## 🔧 التخصيص والتطوير

### تغيير الألوان:
عدّل المتغيرات في بداية ملف `css/style.css`:
```css
:root {
    --primary-color: #007bff;    /* لونك الأساسي */
    --secondary-color: #6c757d;  /* اللون الثانوي */
    /* ... */
}
```

### إضافة دورة جديدة:
في ملف `courses.html`، أضف بطاقة دورة جديدة:
```html
<div class="col-lg-4 col-md-6 course-item" data-category="your-category">
    <div class="card h-100 course-card">
        <!-- محتوى البطاقة -->
    </div>
</div>
```

### تعديل النماذج:
في ملف `contact.html` أو أي نموذج آخر، يمكنك:
- إضافة حقول جديدة
- تعديل قواعد التحقق في `js/script.js`
- تخصيص رسائل الخطأ
